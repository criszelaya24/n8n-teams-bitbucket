Bitbucket Teams Notifications

Get a card in a Teams channel whenever something happens in a Bitbucket repository: a pull request is opened, approved, merged or commented on, or a pipeline runs.

BitbucketRepository event
→
n8nBuilds the card
→
TeamsPosts in your channel

What you get notified about

AreaEvents
Pull requests
CreatedUpdatedApprovedChanges requestedComment createdMergedDeclined
Pipelines / builds
Build status createdBuild status updated

Each card shows the title, who did it, project, repository, branches, reviewers and a button that opens the pull request or pipeline directly.

Setup

  1. Create a workflow in the Teams channel

    In the channel where you want to receive notifications, create a Workflow that posts a message when a webhook request is received (the “Post to a channel when a webhook request is received” template). When it is created, Teams gives you a URL. Copy it.

  2. Import the workflow into n8n

    Import bitbucket-n8n.json into n8n (Workflows → Import from file). The full workflow is below: copy it and paste it onto an empty n8n canvas, or save it as bitbucket-n8n.json and use the import option.

    After importing, replace the Teams URL in Send to Teams.

  3. Add the Teams URL

    Open the Send to Teams step, paste the URL from step 1 in the URL field, then activate the workflow.

  4. Get the webhook URL from n8n

    Open the Webhook step and copy the Production URL. This is the address Bitbucket will send events to.

  5. Configure the webhook in the Bitbucket repository

    In the repository go to Repository settings → Webhooks → Add webhook, then:

    • Title: any name, for example “Teams notifications”
    • URL: the Production URL from step 4
    • Triggers: choose Choose from a full list of triggers and select:
      • Pull Request: Created, Updated, Approved, Merged, Declined, Changes request created, Comment created
      • Repository: Build status created, Build status updated

  6. Receive notifications

    Open or update a pull request, or run a pipeline. A card appears in the Teams channel.

Good to know

  • One workflow can serve many repositories. Add the same webhook URL in each repository.
  • To send notifications to a different channel, create another Teams workflow and use its URL in Send to Teams.
  • Events that aren’t in the list above are ignored.
